# Code of Conduct

Pixel Pets is a small father-and-son project. We want this to be a friendly, welcoming place for kids, parents and makers — anyone who shows up curious about the project should feel comfortable joining in, asking questions, suggesting things, or sending a PR.

## In short

- **Be kind.** Assume good intent.
- **Disagreements are fine; personal attacks aren't.** Critique ideas, not people.
- **No harassment, slurs, doxxing, or any of the obvious bad stuff.**
- **Remember there's a 10-year-old in the loop.** Justus reads the GitHub issues. Keep tone reasonable.
- **If something feels off**, contact the maintainer privately — see [`SECURITY.md`](SECURITY.md) for the reporting channel. It works for conduct issues too.

## The longer version

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which we treat as the long-form fallback if a situation arises that isn't obviously covered above. We aren't going to enforce every Covenant clause to the letter — this is a hobby repo, not a Foundation — but the principles apply.

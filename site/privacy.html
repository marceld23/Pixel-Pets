Privacy

This page is hosted on GitHub Pages. We do not run any analytics, ad networks, or tracking beacons. No cookies are set by the site itself.

What the page stores locally

One key in your browser's localStorage:

  • lang — your preferred UI language.
  • petsound-muted — whether the demo pet's sounds are muted.

Both can be cleared from your browser at any time; the page will simply pick its defaults again on the next visit.

What GitHub Pages logs

GitHub Pages records HTTP request metadata (IP address, user agent, timestamp) for abuse-prevention purposes. We do not have access to that data ourselves. For details see GitHub's privacy statement at

docs.github.com/site-policy/privacy.

What the firmware does

The firmware (the actual virtual pet that runs on M5Stack hardware) is open source under the MIT license. It optionally fetches your approximate location from ip-api.com and weather data from open-meteo.com so the bedroom window mirrors your local weather. It optionally streams audio from public broadcasters (WDR Die Maus, Fun Kids UK) when web radio is active. No accounts, no telemetry, no upload of any user data. All those features can be turned off.
